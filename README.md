# EventSetProcessor Benchmarks

## Setup

### ROOT version

The code in this repository is guaranteed to work with [this tag of ROOT](https://github.com/enirolf/root/releases/tag/v6-37-escience25-eventsetprocessor).

Build instructions for ROOT can be found [here](https://root.cern/install/build_from_source/#quick-start). The specific build commands used in the paper evaluation is as follows:

```sh
cmake -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=<INSTALL_DIR> -Dccache=on -During=on -Dminimal=on -Dtesting=off <SRC_DIR>
ninja install
```
(N.B.: `Ninja` and `-Dccache` are optional and can be omitted if desired. Replace the second line with `make install` in case `Ninja` is not used).

The evaluation code can subsequently be built by running `make` in this directory.

Test data can be generated by running `./make_data`.

To run all benchmarks, simply execute `run.sh`.
